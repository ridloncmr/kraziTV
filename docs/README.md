# Documentation

This folder contains project documentation that is too detailed or too specific for the root README.

## Sections

- `specs/` - Feature folders, feature goals, and feature-scoped vertical-slice specs
- `adrs/` - Architecture decision records
- `implementation_plan/` - Milestones, task breakdowns, and sequencing
- `knowledge_base/` - Research notes, references, commands, and operational knowledge

## README Convention

Directory `README.md` files are indexes or feature goals. Detailed behavior specs should live in numbered spec files under a feature folder's `specs/` directory.
