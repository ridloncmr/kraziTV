# Handoff

Adapted from Matt Pocock's `handoff` skill: https://github.com/mattpocock/skills

Use this skill to preserve context for the next session.

## Include

- Goal of the session
- Decisions made
- Files changed
- Current git status
- Commands run and results
- Tests/verification completed
- Known blockers
- Recommended next steps

## Keep It Useful

Be concise. Do not narrate every minor step. Preserve the information another agent needs to continue safely.
