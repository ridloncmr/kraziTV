# Research

Adapted from Matt Pocock's `research` skill: https://github.com/mattpocock/skills

Use this skill for questions that need evidence from primary sources or careful technical notes.

## Sources

Prefer:

- Official docs
- API references
- Standards/specifications
- Maintainer examples
- Source code when docs are incomplete

Avoid relying on unverified blog posts unless they point to primary sources.

## Output Location

Save durable research in `docs/knowledge_base/`.

Use filenames like:

- `plex-live-tv.md`
- `xmltv.md`
- `m3u.md`
- `ffmpeg-mpeg-ts.md`
- `ffprobe-json.md`

## Research Note Shape

Include:

- Question
- Findings
- Sources
- Implications for kraziTV
- Open questions
