# Off air and other screens

A channel always broadcasts, even when no program is scheduled. Here are
the three things viewers can see instead of a program.

## Off air

**Off air** is planned time with no program in it. It happens only around
[specials](Specials): before one, when regular programming cannot fit
another whole program in; or inside one, when its programs end before the
end you set.

- **Viewers** see a black screen reading **Programming resumes at 8:00
  PM**, with silence. The time is when listed programming starts again, in
  kraziTV's programming timezone.
- **The Program Guide** and the Plex guide list it as **Off air**.
- **My Channels** and **Live Monitor** say **Off air — programming resumes
  at 8:00 PM**.

If you would rather not have the gap, move the special's start to when the
program before it ends. If that program is on the air when you save, the
preview offers **Let it finish**, which does this for you.

## Programming offline

**Programming offline** appears when a program cannot be played: its file
is missing, cannot be read, or stopped partway. The channel stays on the
air with this card until the next scheduled program begins, so viewers are
never disconnected.

Check the file in [Media Library](Media-Library). While the catalog still
lists it as available, the program keeps failing until the file is fixed or
the root is scanned again. Once a scan marks it **Missing** or **Could not
be read**, the channel skips it in future turns.

## Nothing scheduled

If a channel has nothing it can play at all, there is no broadcast: My
Channels reports that nothing is scheduled and TV shows **No signal**.
[Troubleshooting](Troubleshooting#a-channel-says-nothing-is-scheduled-right-now)
walks through the causes.
